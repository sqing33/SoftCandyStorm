# 核心玩法规格

## 基本类型

- 视角：2D 俯视角
- 操作：玩家只控制移动，攻击自动释放
- 局长：标准 10 分钟
- 失败：生命值归零
- 胜利：坚持到 10:00 并击退最终风暴眼事件
- 核心循环：移动躲避 → 自动攻击 → 击杀掉落糖晶 → 升级三选一 → Build 成型 → Boss 检验

## 单局流程

### 进入局内

玩家选择：

- 角色
- 初始地图
- 可选初始武器
- 可选难度或风暴强度

进入地图后：

- 玩家生成在地图中心或安全区。
- 初始武器自动装备。
- 第一波软糖怪延迟 2-4 秒出现，给玩家理解空间。

当前 GameCore / Runtime 已采用固定 3 秒开局敌群缓冲：GameCore 在重置后等待 3 秒才允许普通波次刷怪，Runtime HUD 会在无敌群时显示开局缓冲倒计时。

### 局内时间轴

标准 10 分钟局：

| 时间 | 设计目标 | 内容 |
|---|---|---|
| 0:00-0:30 | 安全开局 | 少量蹦蹦软糖，教玩家移动和拾取 |
| 0:30-1:30 | 基础压力 | 小怪数量上升，第一次升级出现 |
| 1:30-3:00 | Build 分叉 | 出现速度怪、肉盾怪，引导选武器 |
| 3:00-4:00 | 小 Boss | 第一个精英或 Boss 检查输出 |
| 4:00-6:30 | 中期展开 | 怪物组合增加，控制/范围武器开始重要 |
| 6:30-8:30 | 高压怪潮 | 怪潮密度提升，屏幕压力增强 |
| 8:30-9:30 | 最终准备 | 掉落更多糖晶，给最后升级机会 |
| 9:30-10:00 | 风暴眼 | 最终 Boss 或大规模混合波 |

## 玩家移动

### 输入

正式游戏：

- 键盘 WASD / 方向键
- 手柄左摇杆
- 可选移动端虚拟摇杆

Harness / Bot：

- 8 方向离散动作
- 连续二维向量
- 原地不动
- Replay 输入序列

### 移动参数

基础角色参数：

- 移动速度
- 最大生命
- 拾取半径
- 体型半径
- 受击无敌帧
- 生命恢复
- 冲刺能力，首版可不做

### 受击规则

首版建议：

- 敌人与玩家接触造成持续伤害。
- 伤害按秒计算，避免碰一下瞬死。
- 玩家受击时有短暂闪烁反馈。
- 如果多个敌人同时接触，伤害可以叠加，但需要有上限或递减，避免被瞬间融化。

## 自动攻击系统

### 武器释放

每个武器有：

- 冷却时间
- 目标选择
- 伤害
- 范围
- 投射物数量
- 穿透
- 持续时间
- 视觉特效
- 命中音效

目标选择类型：

- 最近敌人
- 血量最高敌人
- Boss 优先
- 玩家周围随机方向
- 玩家移动方向
- 固定环绕轨道
- 地面随机落点

### 武器类型

首版推荐 6 类：

1. 投射物
   - 彩虹糖弹、糖晶长枪。
   - 适合远程、单体、穿透。

2. 环绕物
   - 棒棒糖回旋镖、棉花糖护圈。
   - 适合防御和近身。

3. 范围爆炸
   - 跳跳糖地雷、汽水喷泉。
   - 适合清群。

4. 持续区域
   - 焦糖黏地、薄荷冰霜。
   - 适合控制。

5. 召唤物
   - 布丁炮台、糖果小帮手。
   - 适合站位和自动输出。

6. 光束/引导
   - 焦糖光束、星糖射线。
   - 适合 Boss 和高血目标。

## 经验与升级

### 掉落物

击杀敌人掉落糖晶碎片。

糖晶属性：

- 经验值
- 颜色/大小
- 吸附距离
- 存活时间，首版可无限存在

### 升级节奏

升级所需经验应递增，但不能让玩家长时间没有选择。

目标：

- 前 1 分钟至少升级 1 次。
- 10 分钟局平均升级 12-20 次。
- 高经济流可以达到 22 次以上。

### 升级选择

每次升级给 3 个选项：

- 新武器
- 升级已有武器
- 新被动
- 升级已有被动
- 稀有糖果事件，后续加入

选择界面暂停游戏。

选项需要清楚显示：

- 名称
- 图标
- 当前等级或新获得
- 简短效果
- 目标选择和武器定位
- 标签，例如范围、控制、Boss、经济

## 武器升级与进化

### 基础升级

每个武器 5 级或 8 级。

升级维度：

- 伤害
- 冷却
- 数量
- 范围
- 穿透
- 持续时间
- 特效规模

### 进化规则

进化建议采用：

```text
指定武器达到满级 + 指定被动达到一定等级 + 击败 Boss 或拾取风暴糖罐 = 进化武器
```

例子：

- 彩虹糖弹 + 糖晶放大镜 = 彩虹糖流星雨
- 棉花糖护盾 + 大号糖罐 = 棉花堡垒
- 焦糖黏地 + 奶油发条 = 焦糖漩涡
- 汽水喷泉 + 泡泡鞋 = 汽水火山

## 敌人与刷怪

### 敌人基础属性

- 生命
- 速度
- 伤害
- 体型
- 经验掉落
- 分数
- 碰撞类型
- 行为类型
- 波次权重

### 行为类型

首版行为：

- 直线追踪
- 加速冲刺
- 慢速肉盾
- 死后分裂
- 留下减速区域
- 周期性跳跃
- 围绕玩家侧向移动

### 刷怪规则

刷怪系统需要支持：

- 时间段
- 敌人池
- 权重
- 间隔
- 每次生成数量
- 敌人上限
- 精英倍率
- Boss 标记

## Boss 设计

Boss 不应只是血厚大怪。每个 Boss 要有至少一个机制：

- 冲撞
- 分裂召唤
- 地面危险区
- 旋转弹幕
- 暂时无敌
- 改变刷怪节奏

首版 Boss：

1. 暴走搅糖机
   - 直线冲撞，召唤小软糖。

2. 巨型熊糖王
   - 高血量，跳跃落地震波。

3. 裂星糖罐核心
   - 最终 Boss，周期性释放糖浆风暴。

## 结算

失败结算：

- 存活时间
- 击杀数
- 等级
- 最高武器
- 死亡原因
- 伤害来源
- 建议流派，不要过度教学

胜利结算：

- 是否击败最终 Boss
- 解锁糖晶
- 新内容解锁
- 本局 Build 总结
- 可保存 replay

## Meta 成长

首版可以轻量：

- 解锁新角色
- 解锁新武器
- 解锁新被动
- 提高初始选择池
- 收集图鉴

避免太早做复杂永久数值成长，否则会干扰 Harness 平衡。
