# Demo Buildcraft Repair v2 Candidate Pack

本批候选用于修正首轮 300 秒小矩阵暴露的构筑平衡问题，不是正式内容。

v2 调整方向：

- 降低护盾、拾取成长和冷却丝滑带来的无脑稳定性。
- 降低近身范围清场和控制武器的安全输出。
- 保留高风险爆发路线的 Boss 压制身份，后续用 Bot 矩阵验证。

- 范围清场：`sugar-drum` + `rhythm-ribbon` -> `sugar-drum-crescendo`
- 减速控制：`snowcone-fan` + `frosty-straw` -> `snowcone-blizzard`
- 拾取成长：`jellybean-magnet` + `taffy-pocket-map` -> `jellybean-treasure-orbit`
- 护盾容错：`wafer-guard-rail` + `marshmallow-vest` -> `wafer-castle-rail`
- 高风险爆发：`fizzy-fuse-pop` + `crackling-sugar-fuse` -> `fizzy-grand-finale`

该批次只允许进入 candidate flow。通过 Schema、静态预算、GameCore 加载、Bot 仿真、Replay 回归和人工试玩前，不得复制到 `content/base_demo` 或 `accepted_content`。
